# Contributing

Discuss substantial changes in an issue before implementation. Keep pull requests
focused and write code, tests, commit messages and pull request descriptions in
English. Follow [development setup](docs/develop/setup.md) and run the applicable
[verification commands](docs/develop/verification.md).

Use a dedicated branch and signed commits. Changes to `main` go through a pull
request, successful CI and resolved review conversations, then a squash merge.
Do not include credentials, production data or generated build outputs.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
